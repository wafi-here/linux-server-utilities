# How to use it

```bash
git clone https://github.com/wafi-here/linux-server-utilities
cd linux-server-utilities


#to use netplan confi
chmod +x ./configure-netplan.sh
sudo bash ./configure-netplan.sh

#to use dhcp ntp confi
chmod +x ./setup-dhcp-......(name of file)
sudo bash ./setup-dhcp.....(name of file).sh

#to use dns confi setup
chmod +x ./setup-dns.sh
sudo bash ./setup-dns.sh
```
